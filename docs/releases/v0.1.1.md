PalmierWin now defaults to NVIDIA Nemotron 3 Ultra for the editing assistant, with streamed tool calling, thinking enabled, and a longer request timeout.

Download **PalmierWin-0.1.1-x64-Setup.exe** to install, or **PalmierWin-0.1.1-x64-Portable.exe** to run without installation. Checksums are in **SHA256SUMS.txt**.

- Existing saved provider settings are preserved. NVIDIA defaults apply to new installations.
- Enter your NVIDIA API key privately in Settings. Personal API keys are not bundled in public downloads.
- Streamed tool arguments are assembled and checked before edits execute. Provider overload and timeout errors are reported in the editor.
- Version tags now publish a preview release with the Windows files automatically after a successful build.

Validation: all 34 automated tests passed on Windows for the NVIDIA integration; a live NVIDIA read-only tool-call round trip also passed. This release workflow runs the tests again before packaging and publishing.

This is an unsigned Windows x64 preview. Full Palmier feature parity remains incomplete; see [the feature comparison](https://github.com/Ellosan/PalmierWin/blob/v0.1.1/docs/PARITY.md).
