PalmierWin has a clearer editing workspace, task-based Settings, and GitHub updates with Stable and Beta channel selection.

Download **PalmierWin-0.1.2-beta.1-x64-Setup.exe** to install, or **PalmierWin-0.1.2-beta.1-x64-Portable.exe** for portable use. Checksums are included in **SHA256SUMS.txt**.

- Settings now separates Project, AI Assistant, and Updates, with keyboard navigation and clear save behavior.
- Larger labels, stronger contrast, a prominent Import action, a clearer assistant panel, visible focus, and restrained motion improve desktop usability.
- Space activates focused controls correctly; menus support arrows, letter navigation and Escape with focus return. Errors can be dismissed when ready.
- **Settings → Updates** lets you choose **Release — Latest · Stable** or **Pre-Release — Beta**. Beta also receives stable versions; changing channels never downgrades the app.
- Installed Windows copies can check and download updates automatically, then restart to install after saving project recovery. An active video export blocks restart.
- Portable copies check the same channels and offer a matching portable download; replacement is manual.

Install this version manually once to gain the updater. Older builds do not include it. Public downloads do not contain personal NVIDIA API keys.

Validation: 51 automated tests, 14 browser design/update-control checks, 11 browser editing checks, and a live read-only GitHub release check. Windows CI repeats the automated tests and builds both executables before publishing.

This is an unsigned Windows x64 Beta. Physical Windows restart-and-install behavior and Narrator are not validated in the Linux development environment. Full Palmier parity remains incomplete; see [the feature comparison](https://github.com/Ellosan/PalmierWin/blob/v0.1.2-beta.1/docs/PARITY.md).
